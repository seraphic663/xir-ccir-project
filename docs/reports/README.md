# 报告材料

这里保留最新 v3.0 release 中的三组可阅读材料。PDF 是交付/打印版本，Markdown 便于 AI 快速检索，TeX 用于逐句和逐表核对；构建脚本在 `build-scripts/`。

| 目录 | 内容 |
|---|---|
| `chinese-two-page/` | 中文两页方案介绍：PDF、Markdown、TeX |
| `english/` | 英文技术报告：PDF、Markdown、TeX |
| `chinese-lrat-style/` | 按 LRAT 风格排版的中文稿：PDF、TeX、说明和 Windows 构建脚本 |

报告中的平台数字和边界应结合 `docs/project/FACTS.md` 阅读。报告不是原始比赛导出，也不意味着本仓库包含训练数据或模型。
